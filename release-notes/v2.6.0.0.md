## v2.6.0.0 — Microsoft S/MIME for Outlook Web Access (OWA)

**Feature release — enables Microsoft S/MIME signing & encryption in Outlook Web Access.**

### Summary

v2.6.0.0 integrates the **Microsoft S/MIME extension** for Outlook Web Access into the **Balanced** and **Advanced** hardening tiers. The S/MIME extension (`maafgiompdekodanheihhgilkjchcakm`) is now force-installed via `ExtensionInstallForcelist` from Balanced, and allow-listed with `override_update_url` in `ExtensionInstallAllowlist`/`ExtensionSettings` at Advanced. Two new Advanced-tier policies — `NativeMessagingAllowlist` (`com.microsoft.outlook.smime.chromenativeapp`) and `NativeMessagingUserLevelHosts` (DWord 1) — keep the Microsoft native messaging host available so OWA can sign and encrypt email. Brave version is unchanged (1.94.117 / Chromium 152.0.7977.64) — this is a policy and scripting feature release, not a Brave bump.

### Added

- `NativeMessagingAllowlist` → **Advanced** — `com.microsoft.outlook.smime.chromenativeapp` native messaging host (required by Microsoft's OWA S/MIME extension for signing/encryption)
- `NativeMessagingUserLevelHosts` → **Advanced** — DWord 1 (keeps user-level native messaging hosts active; required by Microsoft OWA S/MIME guidance)
- **Microsoft S/MIME extension** (`maafgiompdekodanheihhgilkjchcakm`) → force-installed from **Balanced** via `ExtensionInstallForcelist`; allow-listed with `override_update_url` in `ExtensionInstallAllowlist`/`ExtensionSettings` at **Advanced**
